# Glossário PT-EN do Ouvidômetro

Termos usados em `painel/textos.js` e no `index.html` da raiz. Ao incluir um texto novo, siga esta tabela.

| Português | English | Observação |
|---|---|---|
| manifestação | submission | Gênero que reúne reclamação, denúncia, elogio, sugestão e solicitação. Evita "complaint", que seria só um dos tipos. |
| ouvidoria | ombudsman office | "Ombudsman" sozinho aparece em "ombudsman submissions" e "ombudsman platform". |
| órgão | agency | Nomes próprios de órgãos ficam como estão na base da CGU. |
| prazo legal | legal deadline | |
| prazo | deadline | |
| no prazo / respondida no prazo | on time / answered on time | |
| fora do prazo | late | Em gráficos e rótulos curtos. Em frases, "past the deadline" ou "missed the deadline". |
| prazo vencido | expired deadline | |
| pendência vencida | overdue pending submission | Forma curta em cabeçalho de tabela: "Overdue pending". |
| prorrogação / prorrogado | extension / extended | "Prazo prorrogado" = "Extended deadline". |
| suspensão do prazo | deadline suspension | |
| pedido de complementação | request for additional information | |
| resposta conclusiva | final response | |
| teto (de 60 dias) | ceiling (of 60 days) | |
